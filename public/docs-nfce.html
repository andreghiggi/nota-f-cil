🧾 API NFC-e — Modelo 65 (Consumidor)

Base URL: https://vdzkhealunurfgrujekg.supabase.co/functions/v1/nfce-api

Guia de integração para emissão, consulta, cancelamento, inutilização e contingência de NFC-e.

Autenticação: todas as requisições exigem o header x-api-key: SEU_TOKEN_API. Gere tokens no painel em Tokens API.
Pré-requisitos da NFC-e: certificado digital válido, CSC (Código de Segurança do Contribuinte) com ID CSC cadastrados e uma série fiscal ativa do tipo nfce.

3. Cancelamento

POST /nfce-api/{id}/cancelar
{ "justificativa": "Venda cancelada pelo cliente" }

Justificativa entre 15 e 255 caracteres. Prazo legal da NFC-e: 30 minutos após a autorização.

4. Inutilização

POST /nfce-api/inutilizar
{
  "empresa_cnpj": "12345678000199",
  "serie": "1",
  "numero_inicial": 100,
  "numero_final": 105,
  "justificativa": "NFC-e nao consta na base de dados da SEFAZ"
}

5. Contingência

Quando a SEFAZ fica indisponível, a NFC-e é emitida em contingência offline e transmitida automaticamente assim que o serviço volta. Para forçar o retorno ao modo online:

POST /nfce-api/abortar-online
{ "empresa_cnpj": "12345678000199" }

6. Webhooks

EventoDescrição
nfce.autorizadaNFC-e autorizada pela SEFAZ
nfce.rejeitadaNFC-e rejeitada pela SEFAZ
nfce.canceladaNFC-e cancelada com sucesso
nfce.denegadaNFC-e denegada pela SEFAZ

Todos os envios trazem assinatura HMAC-SHA256 no header X-Webhook-Signature e o segredo configurado em X-Webhook-Secret. Reenvio automático em até 3 tentativas com backoff.

8. Cadastro automático de empresa (chave de parceiro)

POST /nfe-api/register — vale para NF-e e NFC-e.

Enviando o header x-partner-key, a empresa nasce dentro da conta do parceiro e fica isolada das demais. Sem esse header, o comportamento atual é mantido.

POST /nfe-api/register
x-partner-key: pk_sua_chave_de_parceiro

{
  "cnpj": "12345678000199",
  "razao_social": "Empresa Exemplo LTDA",
  "uf": "SP",
  "municipio": "SAO PAULO",
  "codigo_municipio": "3550308",
  "regime_tributario": "simples_nacional"
}

// 201 -> { "success": true, "data": { "api_key": "sk_live_...", "empresa_id": "uuid" } }
// 401 PARTNER_INVALID    -> chave de parceiro inválida ou inativa
// 409 ALREADY_REGISTERED -> CNPJ/CPF já cadastrado
